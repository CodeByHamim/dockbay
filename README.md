# Dockbay

**Deploy with git push. Never get a surprise bill.**

Dockbay is an early-stage developer hosting platform (PaaS) built around two ideas:
- **Flat, predictable monthly pricing**
- **Hard spend caps**: you set a limit, and Dockbay pauses or throttles instead of charging you more

> Status: research and validation phase. The product is not live yet, and Dockbay is a working name. Plans, pricing and features are subject to change.

## Planned features
- Connect a GitHub repo and deploy on every push
- Custom domains with automatic HTTPS
- Logs, metrics and one-click rollbacks
- Fixed plans with a monthly spend cap and usage alerts
